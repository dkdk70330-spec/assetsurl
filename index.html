GitHub 연결

깃허브 '공개 저장소' 하나를 이미지 저장소로 사용합니다. 토큰은 이 브라우저에만 저장됩니다.

GitHub 토큰과 이미지는 개발자 서버로 전송되지 않으며, 브라우저에서 GitHub API로 직접 연결됩니다. 토큰은 웹앱 저장소와 분리된 이미지 저장용 Public 저장소 1개에만 접근하도록 만들고, Contents: Read and write 권한만 주세요. 토큰 권한 및 연결은 깃허브토큰.jpg를 참고하세요.

캐릭터 추가

이름은 관리용이며, 실제 URL에는 들어가지 않습니다. 추가하지 않고 끄려면 ESC를 누르세요.

EXIF 제거

JPG, JPEG, WebP, PNG 등 이미지의 EXIF를 지웁니다. 모든 처리는 브라우저 로컬에서 진행됩니다.

주의: 출력은 항상 PNG이며, 투명도가 제거됩니다. GIF·움짤 등 애니메이션 이미지는 정지된 한 프레임으로 변환될 수 있습니다.

이미지 URL 불러오기

이미지 주소를 한 줄에 하나씩 입력하세요. pbs.twimg.com 주소는 wsrv.nl을 통해 임시로 불러온 뒤 기존 EXIF 제거 과정으로 넘깁니다.

변환된 wsrv.nl 주소는 저장하지 않습니다. 이미지를 브라우저로 가져오는 데만 사용하며, 최종 결과는 기존과 동일하게 PNG로 재인코딩됩니다. 일반 외부 URL은 원본 서버의 CORS 정책에 따라 불러오지 못할 수 있습니다.
